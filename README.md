# Clara Smart Home

## AI Documentation

This repository includes a dedicated AI Context Pack designed to help AI assistants and new contributors quickly understand the Clara Smart Home architecture, project structure, development standards, and technical decisions.

### Quick Start

Start with:

1. `docs/ai-context/AI_ONBOARDING.md`

### Recommended Reading Order

1. **AI_ONBOARDING.md**
   - Project overview and onboarding guide.

2. **AI_INDEX.md**
   - Master repository and system index.

3. **ARCHITECTURE.md**
   - Application architecture and system design.

4. **REPOSITORY_MAP.md**
   - High-level project structure.

5. **WIDGET_ARCHITECTURE.md**
   - Explanation of the Clara Widget Architecture Standard (CWAS) vs Legacy monolith.

6. **GOLDEN_RULES.md**
   - Core project maintenance rules, UI separation guidelines, and architectural contracts.

7. **TECHNICAL_DEBT.md**
   - Catalog of known issues, tight coupling points, and refactor priorities.

8. **AI_CONTEXT_SUMMARY.md**
   - High-level condensed summary useful for quickly injecting AI context without loading full documents.

### Other Documentation

- **API_INTEGRATIONS.md**: Details on REST APIs, Google Cast, Matter, and Tuya SDK integrations.
- **DATABASE_GUIDE.md**: Database providers, caching stategy, and data ownership.
- **DEPENDENCIES.md**: Catalog of critical build dependencies and risk assessments.
- **FILE_INDEX.md**: Exhaustive catalog mapping filenames to their architectural purpose.

All documentation files are located under the `docs/ai-context/` directory.
